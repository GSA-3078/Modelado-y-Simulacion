# 📌 Descripción del repositorio

Este repositorio reúne las **prácticas de la asignatura de Modelado y Simulación**, cuyo propósito es **representar, analizar y simular sistemas dinámicos**, relacionando el comportamiento físico de un proceso con su representación matemática.

Cada práctica incluye el **código en MATLAB**, la **documentación del procedimiento** y los **resultados obtenidos**, de modo que puedan reproducirse y consultarse de forma independiente.

La ruta general de trabajo en cada práctica es:

```text
📐 Planteamiento del sistema
   │
   ▼
🧮 Modelo matemático
   │
   ▼
⚙️ Configuración de parámetros
   │
   ▼
🖥️ Simulación en MATLAB
   │
   ▼
📈 Análisis de resultados
   │
   ▼
✅ Conclusiones
```
